# 双图制作规划（每题仅2张）

## 选题
- 编号/标题：
- 内容类型：
- 读者群：
- 已核实的要点（带来源）：
- 不应出现的未证实内容：
- 参考视觉身份/配色：
- 真实现场/照片授权情况：

## P1.png 封面（1080×1440）
- 只回答的一个问题：
- 画面主主体（足够明显）：
- 大标题（1–2行）：
- 副标题（可选）：
- 可出现的真实数字：
- 视觉身份角标（必填）：
- 禁止元素：无关icon、伪造logo、未经授权真人、虚假数字。

## P1自动质检
- [ ] 单独一张3:4 PNG
- [ ] 标题可读且不过度推断
- [ ] 真实教学现场与概念示意已明确区分
- [ ] 版权/隐私合规
- [ ] 视觉身份角标可读
- [ ] 无拼版/多页
通过后直接继续P2，不等待人工逐张确认。

## P2.png 内容解释（1080×1440）
- 唯一主要解释任务：
- 内容节点（不超过3个）：
- 主视觉对象：
- 源自原始材料的关键事实与数字：
- 必须写清的适用范围/科学边界：
- 视觉身份角标（必填）：
- 与P1一致的颜色/字体/风格：

## P2自动质检
- [ ] 独立PNG，不是P1复制或拼图裁切
- [ ] 没有捏造数据图或政策规定
- [ ] 有清晰的关键解释和边界
- [ ] 字体可读
- [ ] 视觉身份角标可读
- [ ] 与正文/来源一致
- [ ] 无未授权肖像/假现场

## 最终
- P1结果：成功/失败 + 重试次数
- P2结果：成功/失败 + 重试次数
- 成品状态：完整（文案+双图+合规）/部分完成
