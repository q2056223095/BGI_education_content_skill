- 编号/标题：
- 内容类型：

- 不应出现的未证实内容：
- 参考视觉身份/配色：
- 真实现场/照片授权情况：

## 强制文字清单与程序化叠加
- [ ] P1.spec.json已保存、title/subtitle/source_label均为准确中文
- [ ] P2.spec.json已保存、title/至少2条有文字的heading+detail/source_label均为准确中文
- [ ] 两张背景都不含生成式乱码、假Logo或伪造真实现场
- [ ] 使用 scripts/render_and_validate.py 叠加中文，不直接将无字背景充作P1/P2
- [ ] 每页生成P1.qa.json/P2.qa.json，且运行verify为PASS
- [ ] 整批运行scripts/verify_batch.py为PASS，另完成视觉与事实核查
- [ ] 缺文字或验证失败时整题标“部分完成”，不计入完整交付

## P1.png 封面（1080×1440）
- 只回答的一个问题：
- 画面主主体（足够明显）：
- 大标题（1–2行）：
- 副标题（可选）：
- 可出现的真实数字：
- 视觉身份角标（必填）：
- 禁止元素：无关icon、伪造logo、未经授权真人、虚假数字。

## P1自动质检
- [ ] 单独一张3:4 PNG
- [ ] 大号准确中文主标题+副标题真实存在、可读且不过度推断
- [ ] 真实教学现场与概念示意已明确区分
- [ ] 版权/隐私合规
- [ ] 视觉身份角标可读
- [ ] 无拼版/多页
通过后直接继续P2，不等待人工逐张确认。

## P2.png 内容解释（1080×1440）
- 唯一主要解释任务：
- 内容节点（不超过3个）：
- 主视觉对象：
- 源自原始材料的关键事实与数字：
- 必须写清的适用范围/科学边界：
- 视觉身份角标（必填）：
- 与P1一致的颜色/字体/风格：

## P2自动质检
- [ ] 独立PNG，不是P1复制或拼图裁切
- [ ] 没有捏造数据图或政策规定
- [ ] 至少2条完整的中文解释要点（标题+说明）和必要边界，字迹清楚
- [ ] 字体可读
- [ ] 视觉身份角标可读
- [ ] 与正文/来源一致
- [ ] 无未授权肖像/假现场

## 最终
- P1结果：成功/失败 + 重试次数
- P2结果：成功/失败 + 重试次数
- 文字叠加与机器QA证据：P1.spec.json/P2.spec.json/P1.qa.json/P2.qa.json
- 视觉/语义审查人或模型、检查状态和具体问题：
