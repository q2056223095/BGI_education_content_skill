# GPT原生双图提示词模板｜V1.2

本模板用于**要求GPT图像模型直接输出最终完整图片**。不可交给程序绘图/代码叠加文字、不可让模型制作两页拼在一起的图。

## 共用画面要求
- 单次调用只制作**一张**独立3:4竖版主题海报（最终导出1080×1440 PNG）。
- 主体清晰，光线、场景、情绪有吸引力；不使用拼图、四宫格、双联、长图、信息卡、表格、流程图、知识解释页。
- **禁止图上任何新闻细节**：不得放事件报道、发布日期、机构新闻、合作名单、培训人数、政策条文/摘要、课程安排、统计数字、科研结论、信息来源URL等。
- 图片只放指定的少量短主题文字，不能自行补充新闻摘要或编造数字。重要事实全部存在《小红书文案.txt》里。
- AI模拟实验室/教学环境不能假装是具体学校、具体班级真实照片，不创建假Logo/假证书，不使用未经许可的真实未成年肖像。
- P1主标题和P2简短引导语均由GPT负责直接绘制在成品上，要求准确、完整、可读。**禁止代码后期补写中文**。

## P1 封面：直接生成一张
主题：〔填写主题〕
画面风格：〔深蓝科技纪实 / 温暖自然科学教育 / 清爽政策相关抽象教育场景〕
唯一主标题：〔简短中文主题标题〕
可选副标题：〔非新闻细节的引导语，不超过12字〕
主要视觉：〔单场景、主对象、构图、光线〕
**只在图中呈现主标题和可选极短副标题，其余全部用画面表达。不要出现日期、人数、新闻报道、政策信息、项目详情、课程要点。**
仅在需要避免AI场景被误认为实拍时，可加非常小的“AI概念示意图”标识。

## P2 视觉延展：直接生成另一张
主题：〔与P1相同主题〕
主要视觉：〔和P1明显不同的完整场景或特写〕
一句简短主题引导语（必填，非新闻）：〔填写6–14字主题短句〕
颜色/质感：〔与P1保持同一组视觉语言〕
**这不是内容信息页，不要新闻，不要解读，不要列表、表格、卡片、流程和数字。重点是强视觉和第二个有辨识度的场景。**
与P1不可拼接、不可复用相同画面、不可由同一张双联图裁剪。

## 生成后视觉检查
1. P1标题正确、完整、可读，P2必须有一句简短、清晰、无新闻细节的中文引导语。
2. P1/P2图上没有新闻内容、事实数字、政策细节和解释长文。
3. 两张都是独立的完整单页，没有拼版/水印/假logo/假真实现场。
4. 科学和教育表达恰当，不夸大认证、医学、学员成果。
5. 画面与小红书正文主题一致。错误时修改提示词、由GPT整张重新生成；单张最多重试2次。
