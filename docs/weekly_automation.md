# 周批次无人值守执行规范

## 运行输入
- 运行日期和时区：默认 Asia/Bangkok，用于日期文件夹命名；用户另指定时以用户要求为准。
- 目标账号：华大生命科学教育与人才培养观察。
- GitHub规则：每次必须重读本仓库主文件和 docs/、templates/。
- 图片：每题 **两张独立 1080×1440 PNG**（不是5张）。
- 批次：每次 3–5 个真实可信选题，不够可减少。
- 交付根目录：由 config.json / 用户本轮明确指定的 Google Drive 文件夹ID；尚未配置时只在本地输出，报告“云盘目标未配置”，**不得沿用旧科研热点固定交付目录**。
- 不代用户发布平台。

## 逐步流程
1. 打开 GitHub 分支当前版本的 SKILL.md、docs/content_scope.md、docs/source_and_compliance.md、docs/editorial_style.md、docs/visual_guide.md、docs/weekly_automation.md、templates/topic_card.md、templates/xiaohongshu_copy.md、templates/two_image_plan.md、templates/batch_manifest.md；缺件明确阻塞。
2. 检索政策发布机关、华大及合作院校官方新闻、可核实科研原文、课程/项目在办信息、可靠职业/学习资料；不要预设每条都是论文。
3. 归并去重，检查时效/状态/来源，候选上限可多于5；不可靠、弱关联或冒用华大关联的剔除。
4. 填写选题卡，先可靠性门槛后6项评分，选出3–5条；排序优先三条核心业务主线，前3篇先保证完整。
5. 逐篇写自然中文完整正文，逐条对齐证据，不编人物和数据；保存 UTF-8 TXT。
6. 逐题先生成P1、自动检查，再生成P2、自动检查；为每页记录视觉身份；将两张输出成独立PNG。
7. 保存来源与合规.md：主张、证据、链接、时效核验、风险、图源及授权状态。
8. 生成候选报告、批次清单；检查所有文件、图片尺寸和内容对应；打包ZIP。
9. 如果已配置明确的云盘根ID，创建当日 YYYY-MM-DD 子目录和各选题目录，上传单文件和ZIP，列目录读回核对存在、数量、大小、可访问性；可行时做字节校验，不能做就写“未完成字节级校验”。
10. 最终只报告经过验证的：候选数、实际完整选题数、文案数、PNG数、每题名字、日期文件夹、实际ZIP链接、缺件、重试与风险。

## 时效
- 教育政策：正式发布/现行有效，确认修订/废止。
- 华大及合作单位新闻：优先30–90天，回顾注明历史发生时间。
- 华大科研成果：优先近期原始论文，历史研究明确年代；预印本显著标注。
- 在办课程和认证：实时核验，不引用已过期报名时间。
- 学习指南：用现行标准与教程，无须强凑“本周最新”。

## 风险与失败
- 来源不可查、科学/政策边界模糊：降低优先级或剔除。
- 图片工具不可用：文案可标为已完成，但“整篇成品”必须标为缺图、部分完成。
- 云盘文件夹无权写/未配置：保存本地成果，绝不宣称上传成功。
- ZIP上传成功但散文件缺件：云端部分交付，不得称“完全交付”。
- 用户资料涉敏或未经公开授权：保留内部使用，禁止在公开文案暴露个人信息。

## 自动化任务建议
单独建立新的周期任务，名称建议“华大教育内容周批次生产”，例如每周一 08:00（Asia/Bangkok），读取本仓库 main 分支最新规范。注意：**仅创建本仓库不会自动创建或修改任何已有计划任务**。
