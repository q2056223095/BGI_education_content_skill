# 单选题双图隔离测试与批量恢复门槛｜V1.4

## 故障复盘
近期出图时多次把3–5个题目的P1/P2、批次报告、统计数字生成在同一张图片里。上一个版本只做了失败拦截，未有效控制生成请求输入。不能把“反复失败”归因为用户要求过高或假设图像服务已实现上下文隔离。

## 这是自动化内部测试，不是对用户的确认
**用户始终要求同一轮任务自动产出P1+P2一起交付，中途不确认。** 此处“先验证”只是无人值守的内部质量控制，**不许因为P1完成就向用户询问要不要继续P2，不许等待用户回复才运行下一页，也不需要再次授权整个批次**。在当前运行里必须继续完成P2或按限制重试，直到同题两张通过或被明确标注缺件。图像生成可以内部顺序或并行，但每张图必须独立，不能使用拼版代替。

## 发布前门槛
**未经“同一选题P1、P2在同轮任务中独立生成+双页自动视觉审核”通过，不得直接尝试3–5题的批量图片生产。** 单题测试只验证图片工作流，不伪装成整批交付；未达到门槛应记录阻塞，保持原本每周任务的文案、来源核验可继续运行，但不得声称图像流水线完全可用。

## 隔离式生成（强制）
1. 上游先完成事实核验、文案和每题双图规划；将本轮选题、新闻、来源和评分保存在工作区，**不要把它们传给图像生成器**。
2. 为当前页面生成一个小而独立的“单页请求包”（仅包含：`page_id`、`topic_slug`、`exact_title`、`visual_subject`、`composition`、`visual_style`、`negative_constraints`）。所有字段只允许围绕当前一题当前一页。**绝不把批次清单、其他主题标题、完成数量、正文、新闻、历史失败图片、ZIP计划传进生图调用**。
3. 能使用独立任务/新会话上下文的图像服务，必须为每张图建立隔离上下文；若服务仅接收整段现有对话、无法保证清除历史对话，则需如实记录“上下文隔离受限”，降低生成批次的保证程度，不能宣称已实现独立会话。
4. 每次工具调用只能请求一个最终PNG页面。禁止在同一生成指令中同时提P1和P2，更不能出现“一套海报”“八张合集”“整批报告”“多选题展示”等表达。
5. 先生成当前题P1；在同一轮无人值守任务中自动审查，无需用户确认；审查通过后立即为同题P2构造**另一份独立的单页请求包**。P2仅用同题主题词/调性，不引用本批其他题。
6. 同题P1与P2必须构图有差异；出现串稿、拼版、双联、新闻内容、伪造Logo、缺中文短句直接FAIL。第一次失败→只编辑这张的简短提示词重试；最多重试2次，仍失败即停，不去生成无关题的替代图。
7. 使用程序只能做文件名、格式、尺寸、文件存在性和ZIP校验，不得程序绘制画面或叠中文字。真实视觉检查必须查看最终图，不能用文件存在证明图合格。

## 单页请求包格式（工具可用时）
```json
{
  "page_id": "P1",
  "topic_slug": "biology-research-skills",
  "exact_title": "科学课，不只是看实验",
  "visual_subject": "一位戴护目镜的学员在实验台独立观察显微镜样本",
  "composition": "单一场景，竖版3:4，主体为人物和显微镜，上方中文标题",
  "visual_style": "蓝白科研纪实、摄影质感、清晰自然光",
  "negative_constraints": "只有这一张图；没有多格、双联、其他选题、新闻事实、政策条文、统计、机构Logo"
}
```
上面是制作请求前的内部约束模板，具体图像工具不一定支持JSON入参；不要假设插件已提供上下文隔离API。调用工具时只传与当前页相关的信息。

## 通过条件
- [ ] 单一选题，P1原生GPT整图单独生成且中文主标题正确；
- [ ] P1一张独立3:4页面，没有拼版/新闻详情/假Logo；
- [ ] 同题P2原生GPT整图单独生成且有一句准确中文短引导；
- [ ] P2一张独立3:4页面，没有拼版/新闻详情/假Logo，构图与P1不同；
- [ ] 两张可验证为真实独立文件，目标1080×1440 PNG；
- [ ] 视觉检查结果及重试计数真实记录，不能以代码文字QA冒充；
- [ ] 不使用伪造场景、真实未成年人肖像或未经许可的第三方素材；
- [ ] 图中的文字不承载任何新闻详情；新闻与学习方法只在小红书正文。

全部通过且实际在本轮工具环境验证后才能认定**单题工作流测试通过**。注意：一次通过只能说明单题验证成功，不证明批量运行稳定。计划中的3–5题批量生产可按“每题串行P1→P2”逐步扩展，首批仍需统计全部失败案例。

## 问题记录
每次失败记录：当前页、真实工具调用方式、失败结果类型（拼版/串稿/漏字/新闻上图/标识/尺寸）、已重试次数、是否因对话上下文隔离限制而无法继续。生成失败图片不计入交付，不应裁切拆分挽救。

## 周计划
单题未通过时每周任务仍可产出真实文案、合规和候选报告，图片部分明确阻塞/缺件。**不要反复无上限触发整批图像生成**。当本轮内部单题冒烟测试确实通过后，可扩大到3–5题，每题都按“隔离P1→验收→隔离P2→验收”逐题执行。
