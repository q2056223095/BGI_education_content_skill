# 来源核验与合规要求

## 按类型找对原始来源
### A. 教育政策
必须优先引用教育部、国务院、地方政府及主管部门的正式文件，核对发布日期、生效状态、适用对象、原文条款、文件性质。区分“要求”“鼓励”“试点”“征求意见”。政策解读属于编辑判断，不可描述为主管机关保证的效果。

### B. 华大教育中心/合作办学新闻
可引用华大教育中心官网、华大集团官方资料、合作高校官宣、公开活动通知、可信媒体原始采访。核对项目主体、时间、合作阶段、活动实际发生状态。用户提供的内部稿件需标识为待批准对外发布，不因材料存在就认定可以公开。

### C. 专业认证/招生/培训
核对现行课程名称、招生状态、证书颁发主体、学习/考核形式、政策认可与资质效力。未经明确证据，不得写“国家认可职业资格”“执业证书”“学位学历”“保就业”“包通过”。认证、课程完成证明、岗位技能培训、职业资格、执业资质是不同概念。

### D. 华大相关科研成果
原始研究以期刊论文、DOI/PMID、预印本、正式科研报告为依据，核对首次发表时间、研究对象、样本量、方法、效应值、结论和限制。机构新闻只能补背景；未找到原始研究不得写成已核验科学发现。预印本标“尚未同行评议”。
- 体外/类器官≠人体疗效；动物≠人体。
- 观察关联≠因果；单细胞计算推断≠功能验证；AI预测≠实验发现。
- 不做诊断、处方、疗效或健康保证。

### E. 科研与职业学习指南
优先官方课程大纲、公开标准、原始教程文档、学术教材和专业机构资料。标明建议是普适方法还是特定场景；不得凭空杜撰岗位薪资、招聘需求统计或教学成效。

## 日期与新鲜度
政策核对现行版本；项目动态优先近30–90天；科研优先近期但经典成果标注历史日期；常青文按现行标准更新。不得用媒体报道日期代替科研首次公开日期。

## 华大关联与品牌
区分：“华大直接开展”“华大合作参与”“行业普遍实践”“有教育启发但与华大无直接关系”。对具体华大产品、课程、平台、机构合作和项目成果，有官方/授权来源方可使用，否则标“待匹配”。

## 未成年人与隐私
使用未成年人姓名、照片、视频、学校、定位、作品、成绩前必须有对应授权及发布依据；优先匿名、去识别化。未经许可不用个人资料或虚构孩子、家长、老师原话。AI示意人物不代表真实学员。

## 视觉来源身份
每张标明一种：现场真实照片（附授权/来源）；官方授权素材；教育概念示意图（非真实现场）；科研科学示意图/科学重绘（非原始数据图）；论文数据图重绘（注明Fig./Table）。
严禁把AI生成的实验室、教师、学员照片冒充华大真实现场；未获许可不直接搬运期刊图片、校方照片或新闻图片。

## 入池前六个问题
1. 对象/事件/论文实际存在吗？是否有可追溯原始链接？
2. 时间和状态准确吗？政策仍有效吗？
3. 华大参与或教育关联是哪一种？证据在哪里？
4. 核心数字、具体结论和限制由什么材料支持？
5. 是否涉及学生隐私、肖像、知识产权或不实资质？
6. 标题是否比证据本身更夸张？

任一核心事实无法核验或有重大隐私风险，暂停并记录原因，不凑数。每篇末尾保留来源清单（标题、单位、时间、URL、核验状态）。
