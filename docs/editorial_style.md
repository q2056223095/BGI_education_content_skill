# 活人感编辑｜教育内容版

## 读者视角
关注“能学到什么、看懂什么、判断什么”，不是简单把部门新闻发出去。读者可能是研究生、大学生、家长、教师、实验/数据岗位人员。每篇明确一个主要对象及其问题。

## 正文默认结构
1. 开头2句：真实场景中的问题、事实或政策变化，不虚构读者反应。
2. 事实：是谁、什么时候、做了什么；可直接核对的原始信息。
3. 方法或解释：课程如何组织、科研怎么做、政策实际针对谁、何种技能有价值。
4. 意义：对该类读者的实用判断；区分事实与编辑观点。
5. 边界：不夸大、不过度外推；自然互动问题。
6. 5–8个准确标签，尽量覆盖领域/受众/方法/主题，避免无关引流标签。

建议300–600字，信息量为先。短句与长句穿插；每段提供一个新增事实/解释/限制。术语第一次出现用自然中文解释。

## 风格禁区
禁止“颠覆认知、重磅炸裂、百分百、保就业、治愈、国家认证”这类超证据承诺；不用“说实话、咱就是说、真正重要的是、你以为其实”等模板化悬念；不编“深夜的实验室”“一位家长告诉我们”等无来源场景。政策不要写成一纸宣传口号，科研内容不要写成论文摘要，机构新闻不要整篇硬广。

## 五种写法
- 政策：政策原文要点 → 人群影响 → 教育实践怎么理解 → 适用边界。
- 专业能力：任务和岗位 → 为什么难 → 要学会的动作/判断 → 学习路径。
- 联合培养：机制介绍 → 真实案例 → 培养环节 → 未经证实不写效果。
- 青少年教育：探究问题 → 学生实际执行步骤 → 观察/记录/评估 → 安全与适龄提示。
- 科研转译：研究问题 → 样本/方法 → 数据与结论 → 证据边界 → 学习启发。

## 交付前检查
逐句标事实出处，删除无证据数字、夸张词和多余重复。确保标题、P1、P2和正文采用相同的证据层级。结尾自然提一个与正文有关的问题，不堆招生CTA。

## V1.2 图轻文重
全部新闻事实、人物与机构名称、发布日期、合作背景、政策条款、课程流程、数字、科研方法与结论、来源及边界，都应写入小红书正文或《来源与合规.md》。P1/P2仅为GPT图像模型直接生成的主题视觉，不能为了“内容完整”把上述详情放到图片。正文应能在完全不看图片的情况下独立理解事件与相关教育价值。
