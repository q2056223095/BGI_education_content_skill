# GPT直接生图的质量检查与失败重做｜V1.2

## 目的
上一轮用户指出两类错误：
1. 纯无字背景被当成用户要求的GPT完整海报，随后用代码叠加中文；
2. P2被做成新闻详情页/政策说明卡片，甚至两页被模型拼成一张。
新版要求**最终成片直接出自GPT图像模型**，图只负责视觉，不承载新闻详情；准确事实与来源全部在小红书正文和合规文档。

## 正确流程
1. **先完成正文和事实核验**。正文保留全部政策/科研/办学新闻细节、来源、日期、数字、研究边界、互动引导。
2. **提炼图片允许的少量文字**：P1短主标题（必须）、可选短副标题；P2可有一句短引导，也可不放文字。禁止新闻事实、摘要、政策要点、数据、课程清单和研究解释。
3. **调用GPT图像生成模型直接制作完整P1**（画面和允许出现的字一次生成），不要产生“只有背景”的半成品。一个请求只生成单张3:4页面，不生成双联/信息拼版。
4. **对最终成图进行真正的视觉审核**（看画面而不是只看文件名）：核对主标题准确、少量文字清楚，视觉内容与主题相关；没有新闻详情、伪文字、无关标志、假现场或未经许可的人像；确认不是多栏详情图或拼图；检查PNG尺寸。
5. P1通过后继续调用GPT生成独立P2，检查另一个构图、场景完整、**不包含任何新闻内容**。P2没有文字但作为一张完整视觉延展图并非失败。
6. 每张初次生成失败后允许**最多2次重新生成整张图**，每次记录原因及变化；**不允许用Pillow/Canvas/SVG/HTML或其他代码补字、画说明卡、遮盖新闻内容再声称GPT原生成图**。
7. P1或P2无法过审，标记该页不合格，整题“部分完成”，不参与“完整成品”统计；保持已完成文案及合格页。
8. 创建本题图片验收.md和整批图片质检汇总.md，标明生成工具、检查人/模型、每页尺寸、文字要求、内容范围、错误、重试、最终结果。

## 必检清单
| 指标 | P1 | P2 |
|---|---|---|
| 由GPT图像模型直接生成最终完整画面 | 必须 | 必须 |
| 独立单张3:4 PNG，目标1080×1440 | 必须 | 必须 |
| 简洁中文主题主标题 | 必须 | 可选 |
| 新闻详情/日期/数字/政策条文/研究结论 | 一律不得出现 | 一律不得出现 |
| 图像角色 | 主题封面 | 第二张不同构图的主题视觉 |
| 错字、乱字、虚构logo、版权/隐私风险 | 不得出现 | 不得出现 |
| 与文案主题匹配，不杜撰事实 | 必须 | 必须 |
| 长段文字、步骤清单、四宫格、新闻信息卡 | 一律不得出现 | 一律不得出现 |

## 异常重试
- P1缺标题、文字错误或超出画布→修改**GPT提示词**，整张重生；
- P2被画成说明页或包含新闻→修改GPT提示词强调“主题视觉、禁止详细文字/数字”，整张重生；
- 两页拼在一图→重新让GPT一次只做一张；不能通过剪开拼图交付；
- 生成工具不可用→如实记录“图片工具阻塞”，不能改用程序绘画替代；
- 图片尺寸不符→如仅有格式尺寸问题，可以在不改变画面内容和文字的前提下做纯尺寸格式转换；转完再看清晰度与完整性。不允许通过裁切拼版救图。
- 超过2次重试仍失败→保留缺件，整题非完整。

## 验收结果写法
- 正文已完成：是/否；新闻及事实是否全部在正文：是/否。
- P1：GPT直接生图/实际尺寸/标题正确/无新闻详情/单页/重试次数/通过或不通过。
- P2：GPT直接生图/实际尺寸/无新闻详情/非信息页/不同构图/重试次数/通过或不通过。
- 证据：图片文件、实际检查记录、报告。**不可使用已废弃的代码叠字QA哈希冒充视觉审核。**

本规范只要求视觉检查与文件属性验证，不要求OCR，也不强制P2出现任何具体文字。
