# 双图视觉规范 V1.2｜GPT直接出图、图轻文重

## 绝对规则
每个选题两张**由GPT图像模型直接生成的完整独立竖版主题图**（最终1080×1440 PNG，3:4），不能拼版或从一张双联图剪出两页，不能程序化绘画/叠文字成为最终图。

**所有新闻详情和知识解释放入小红书正文，不放在图片上。** 图像的主要功能是引发兴趣、建立场景和统一账号视觉形象。

### P1：主题封面
- 必须有可读、准确、简洁的中文主题标题，可有一句很短的非新闻性质副标题。
- 场景/人物/实验对象是主体，画面承担视觉表达，默认没有icon。
- 示例：`测序实验工程师，究竟学什么？` / `从实验室看职业能力`。
- **不要**写“2026年某校288名学生参加培训”之类的日期、数据与新闻事实。

### P2：主题视觉延展
- 与P1相关，但必须是另一张完整、不同构图的画面，体现更深一层的视觉主题。
- 必须有一句短标题或情绪引导语，同时以完整主题画面为主。
- **不要**三段解读、方法步骤、培训课程清单、政策摘要、合作新闻、来源链接、数字表格或多卡片信息图。
- 示例：实验细节特写、导师与学生合作概念场景、青少年观察科学对象的单场景；文字最多一句简短引导。

## 两图文字边界
允许：P1主题主标题、P2一条简短主题标题/引导语、可选短副标题；必要时极小“AI教育概念示意图｜非真实现场”标识（这不是新闻内容）。
禁止：新闻全文/摘录、政策条款、日期/人数/金额/统计数据、具体新闻出处、研究结论、培训课纲、项目说明和解释列表。**注意：来源、边界、具体事实完整写进文案及来源与合规.md，不需为了“资料完整”塞到图上。**

## 根据主题选择画面
- 专业认证：移液器、测序实验、数据处理等科学场景；不出现虚构证书或品牌仪器型号。
- 联合培养：导师与学生、实验室学习、科研合作的概念场景；无授权时不得扮成真实合作院校现场。
- 青少年教育：提问、观察、实验探索；避免未经授权的真实未成年人的可识别肖像。
- 教育政策：抽象教育空间/课堂实验环境，不模拟真实政府文件、红章、条文截图。
- 华大科研成果：科学机制、基因组、时空组学等；不得图绘“假数据”。
- 教育中心动态：未经许可不冒充真实活动现场；使用明确的概念性画面。

## 风格
保持统一的蓝白视觉系统，科学方向可以深海军蓝、青蓝高光、少量亮黄；教育方向可更温暖真实。强视觉主体、清楚的文字对比、适当留白，不要四宫格/堆卡片/漫画分栏。以主题与审美为优先，不为了填满图而放新闻内容。

## GPT成图与自动验收
先将图上允许出现的短文字明确写入提示词，再让GPT**直接生成完整带该文字的画面**；生成后实际查看P1、P2，逐项审核无字/错别字/文字残缺、内容越界、P2变成信息页、拼版、假logo、未授权肖像、比例和视觉差异。失败就重新调用GPT生成整张图，最多2次；不能代码叠字补救。
