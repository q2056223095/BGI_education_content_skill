# 视觉与双图交付规范 V1.1

## 交付硬门槛：有图片不等于有成片
**P1无中文主标题、副标题和来源身份，或P2无标题、2–3条文字解释和来源身份，直接判失败。** 图像模型只负责生成不含文字/Logo的3:4背景；核准的中文字必须由 `scripts/render_and_validate.py` 程序化叠加，避免乱码、漏字和凭空新增数字。P1/P2均要留下 spec JSON 与 qa JSON，并执行单张 verify 及整批 verify_batch.py。**纯背景不得重命名为 P1.png/P2.png 交付。** 检查通过不等于理解语义，仍要视觉目视核对文字可读、图文匹配与真实边界。详见 [质检规范](image_quality_gate.md)。

## 固定数量和格式
每个选题只做 **2张** 独立竖版 PNG：P1.png、P2.png，1080×1440 像素，3:4。不得默认为5张。不得用一张拼版图切割、contact sheet、上下双页、四宫格、截图占位代替两张完整成片。保持同一题的字体、色彩、科学/教育表现风格一致。

## P1：强主题封面
- 目标：用户1秒理解题目、愿意点击。
- 一个清晰主体和一个核心问题，标题1–2行，短副标题可选。
- 默认0个icon；不堆机构logo、二维码、卡片。
- 避免“国家认证”“免试保录”“疗效已证实”等没有来源的结论。
- 封面使用的数字需与正文及原始来源完全一致。

## P2：关键内容解释
- 目标：用户能看懂政策/教学过程/研究证据和真实限制。
- 优先交代对象、真实事实、关键方法/教学步骤/可执行建议、边界。
- 默认0–1个icon，必要时最多2个；最多3层主信息。
- 如需展示统计图，必须依据真实公开数据/论文Fig./Table，标清来源，不许“示意数据曲线”。

## 按栏目选视觉
- 专业认证：实验动作、样本流转、数据处理、岗位能力路径；仪器外观和标志必须有真实来源。
- 联合培养：双导师/科研培养流程、教学与真实科研任务；无真实现场许可就用标注的场景示意，不扮成实际照片。
- 青少年教育：观察、提问、实验设计、记录与汇报；未成年人真实照片必须获得适当发布许可，不推断年龄或学籍。
- 政策：正式文件信息层级、时间点、影响对象和政策逻辑；提高中文可读性，避免虚构公章/政府截图。
- 华大科研成果：科学对象、真实机制或科研技术场景；深海军蓝背景、蓝白高光、少量暖黄可用。严格区分AI示意与研究原图。
- 教育中心动态：优先实际可公开的活动原图；否则用简洁非真实场景的信息设计，不生成假现场。
- 学习指南：工具界面、方法、任务链条、可操作步骤；不要编造实际软件UI截图。

## 视觉规范
- 主体占画面约50%–75%，图片承担信息，不依赖多卡片拼接。
- 优先高对比、清楚的大中文标题，手机号宽度预览仍可读。
- 科研题可采用电影级科学纪实深蓝黑+冷白高光+少量黄；教育实践可偏真实、温暖、简洁；政策类偏浅色/清晰网格，避免所有栏目一个赛博模板。
- 使用华大品牌视觉时尊重官方标识规范与授权；没有官方素材不自制近似品牌Logo。

## 来源身份标注（P1和P2都要）
按实质选择其一，在图角落以可读小字标明：
1. “现场照片｜来源：机构/作者，日期（已获授权）”
2. “官方授权素材｜来源：机构，日期”
3. “AI教育概念示意图｜非真实教学/活动现场”
4. “AI科学示意图｜基于论文内容重绘，非原始数据图”
5. “数据图重绘｜数据来源：原论文 Fig. X / Table X”

不要将“AI生成概念图”标成“华大真实办学成果照片”。若图中出现未授权真实人物、误导性院校标识或伪造实验数据，判失败。

## 无人值守质检状态机
选题通过核验 → 产出正文与两页已核准中文字 spec → P1无字背景与视觉检查 → 程序叠加P1文字 → P1机器verify与视觉语义审查 → 通过后P2无字背景 → 程序叠加P2标题、解释要点及图源 → P2机器verify与视觉语义审查 → verify_batch通过 → 保存成品。每张失败最多再生成2次；仍失败写入缺件，不用拼图填空。

禁止未经本轮用户授权升级为P3–P5。
