# BGI Education Content Skill

**版本：V1.2.0（2026-11-09）**

用于“华大生命科学教育与人才培养观察”账号的选题、事实核验、完整小红书文案以及 **GPT直接生成双图** 的无人值守批次制作规范。

## 账号内容
三条主线：专业认证/技能培养、高校联合培养、青少年科学教育；辅以教育政策、华大科研成果教育转译、教育中心动态与办学成果、科研素养及人才成长指南。每批优选3–5个选题，不凑数。

## 核心要求：图轻文重
- **每题一篇完整文案 + 两张由GPT图像模型直接生成的独立3:4图片**。不再要求5张图。
- **所有新闻事实、背景、日期、政策解读、科研数字、项目/课程细节都写在小红书文案里，不写进图片。**
- P1主题封面：简短大标题、可以有一句非新闻式副标题、强场景。
- P2视觉延展：另一张独立的主题画面，必须有一句简短主题标题/引导语；不做新闻信息页、不堆步骤/要点、不做政策说明卡片。
- 最终画面（包括允许出现的少量中文）必须由**GPT图像模型直接完成**。不要用代码叠字、绘制海报、补贴文字，不要用其他引擎替代。
- GPT出图后逐张检查：错字、无标题的P1、新闻详情混入、拼版、画面误导、版权/隐私、实际比例与分辨率。失败修改提示词并由GPT重新生成，每张最多重试2次。
- 优先确保排名前三完整交付，缺图不得标为完整成品。
