# BGI Education Content Skill

面向“生命科学教育与人才培养观察”账号的选题、核验、文案、双图和批次交付规范。

## 账号定位
以深圳市华大教育中心真实教育实践为特色，聚焦三条核心业务主线：
1. 专业认证与技能培养
2. 高校联合培养与科研人才成长
3. 青少年科学教育

辅以教育政策、华大相关科研成果的教育转译、教育中心动态与办学成果、科研素养与人才成长指南。账号不是单纯的论文热点号，也不做以招生为唯一目的的营销号。

## 默认交付
- 每次择优 3–5 个选题，不为凑数降低可靠性。
- 每题：1 篇小红书完整文案（含 5–8 个标签）+ **P1.png 和 P2.png 两张独立的 1080×1440 PNG** + 来源与合规说明。
- 批次：候选筛选报告、各选题文件夹、批次清单、ZIP整包和云端读回记录。
- 无人值守：自检 P1 后直接生成 P2，无需逐张确认；失败最多重试2次，未完成就明确缺件。
- **不能把合成拼图、四宫格、contact sheet 或长图冒充两张独立图片。**

## 重要约束
- 以最新可核验公开资料或用户提供资料为准；不得杜撰华大课程、合作、认证资质、学员成绩、项目状态。
- “专业认证”不自动等于国家职业资格、执业许可或学历学位。
- 青少年隐私、肖像与学员成果展示需有必要授权与最小化披露。
- 科研结果须区分实验、动物、观察性、临床和计算预测。
- 政策选题按有效政策及适用范围，**不一概要求近7天新论文**。
- 仅使用提供或核实的 Google Drive 交付目标；原科研热点项目的 Drive 文件夹不得擅自挪作新账号交付位置。
- 此仓库是生产规范，不代表已经部署自动化或已经发布内容。

## 初始化
将 SKILL.md 或 docs/weekly_automation.md 作为智能体工作指令。先补充 config.example.json 中缺失的目标云盘文件夹ID（复制为本地 config.json 时不要公开个人令牌）。连接检索、图片生成、GitHub 和云盘能力后，先执行小批次验证，再启动周期任务。
